## 署名、授權與來源模型

新增`provider=wikipedia`、`method=wikipedia_excerpt`，獨立保存文章標題、正整數修訂ID、含時區的修訂時間、固定來源URL、貢獻者歷史URL、CC BY-SA 4.0授權及變更說明。BG subject_id只用來綁定現有卡片，provider仍明確為Wikipedia。沒有將百科偽標為官方或Bangumi。

每張卡片及簡介展開視窗都提供百科署名：文章固定版本、修訂與臺北時間、[維基百科貢獻者](https://zh.wikipedia.org/w/index.php?action=history&title=女學。)的歷史入口、[CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/)及原文節錄的修改說明。實際每張卡的貢獻者連結各自指向自己的文章，不共用女學歷史。這三段節錄文字依來源的CC BY-SA 4.0條款提供，署名與授權資訊隨季度JSON一同公開。

[精確登錄](../../services/reviewed_wikipedia_stories.json)與Python／前端同時綁定卡片、中文名、原名、兩個既有資料庫ID、原文、固定URL、查證時間及完整署名資料；錯季、換字、改修訂、改授權、換域名及偽標提供者均拒絕。來源爬蟲暫缺欄位或回傳別的介紹時保留已查證節錄；改換身分或來源則拒絕寫入，避免後續覆寫。

品質證據報表也記錄Wikipedia provider與修訂節錄範圍，將修訂時間和本次查證時間分開，不把讀取舊修訂說成該日重新創作／更新的百科內容。前端與簡介彈窗用文字節點呈現原文及署名，沒有插入百科HTML。
