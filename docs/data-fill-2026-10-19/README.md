## 剩餘清單與限制

[全部剩餘記錄](remaining.json)共 1,397 筆具有至少一項缺漏，包含各項原因、原查證時間及後續方式。缺漏欄位會重疊，不能直接相加當作作品數。

- [102 筆簡介 CSV](remaining-stories.csv)：76 筆來源空白／過短、14 筆欠缺本季專屬內容、3 筆條目範圍未核准、1 筆混合新聞／演員評論仍無合適節錄、3 筆 API 404、1 筆只有宣傳語、4 筆當季版本官方證據不足。保留上一輪原因及觀察日期，沒有把重讀既有證據標成新請求。
- [1,378 筆資料庫連結 CSV](remaining-links.csv)：列出每季、卡片、原名、既有 BG／AL ID、來源網址與本次時間；《奇喵的畫家》同時缺 BG 與 AL，其餘缺 AL。這是待取得明示連結／精確版本證據的清單，不要求使用者逐筆猜 ID。
- [3 筆播出星期 CSV](remaining-weekdays.csv)：現有欄位只接受單一星期，需先決定每日連播／不定期公開的顯示方式，見[需要確認的項目](needs-your-decision.md)。不把第一個發布日期換算成固定每週播出日。

## 防護與驗證

官方簡介登錄新增兩個精確身分，支援尚無 BG ID 但卡片／中文名／原名／URL 均已人工核對的官方來源。未知 ID 不會變成推測 ID；跨卡片、改名、錯誤提供者及擅自增加 ID 均拒絕。官方星期另有精確身分登錄，來源再次缺欄位時保留查證值；來源回傳衝突星期或改換作品時拒絕覆寫，等待人工重新查證。

[資料不變條件](data-invariants.json)獨立比對全部 37 季 2,150 筆：僅上述 5 筆的簡介／來源或星期變更；既有簡介、名稱、ID、圖片、集數、播出狀態、集數成功查證與最近嘗試時間、卡片順序均保留。Issue #43 的 12 正篇／6 單位與＋版排除、錢天堂 148 已播且總數／終了未知均未改動。
