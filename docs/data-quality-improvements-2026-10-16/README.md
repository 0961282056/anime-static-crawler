## 功能及界線

超出每次 10 筆通知預算的證據先保存至未指派的系統 Issue；下一次即使候選未再出現，也保留待辦。指定審核者可在原審核 Issue 回覆 `C 待查 YYYY-MM-DD`，每天台北時間 11:00 的工作到期提醒一次；A／B 新決定取消舊 C 日期。此回覆不會自動改公開資料。完整操作與故障界線見[資料來源交叉核對與複查](../資料來源交叉核對與複查.md)。

網站顯示來源方式、成功查證、最近嘗試、快照日期、版本範圍及證據連結；AniList 僅標為參考，不冒充兩邊計數範圍已一致。補入簡介亦顯示來源及快照日期。

NHK 專屬抽取器每七天核對一次，失敗隔一天重試。讀不完整、舊節目消失、日期改變或進度倒退時保留舊資料並記錄失敗，不覆寫成功查證時間。其他官方快照仍依既有人工複查政策處理。
