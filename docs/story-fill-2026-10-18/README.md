### 57個完整條目身分逐筆審查

先取得缺漏所涉及36季的最新主來源頁面（全部HTTP200），逐筆確認卡片ID、中文名、原名與版本；再對162個既有Bangumi ID實際查詢API（156個成功、6個HTTP404）。未發起名稱搜尋、未新增或改綁資料庫ID。見[主來源查證](primary-access.json)及[162個條目查詢紀錄](subject-receipts.json)。來源簡介全文放在對應公開記錄，查詢紀錄僅保存雜湊／長度，不重複搬入其他條目的正文。

經逐筆確認，允許57個精確身分使用完整所連結條目的原文，涵蓋64筆季度紀錄。差異包括明示英日別名、季數文字寫法、副標展開／順序、以及已核對的分割季度對應。每筆有獨立範圍理由與源卡觀察，見[完整範圍審查](scope-review.json)。例如：

- 《地獄樂第二季》：第2期／第二期、2026-01-11一致，原文描述殊現增援及人類對天仙的後續戰鬥。
- 《地縛少年花子君2後篇》：來源明列Part2、2025-07-06，對應條目第2クール，原文描述宿泊學習新篇。
- 《米之神！女孩們》《盜墓王》：條目明示來源使用的日文別名，日期與同一動畫版本相符。
- 《一人之下羅天大醮篇》：源卡明列2季度24集，條目亦為24集且原文明列羅天大醮。保留既有中國／日本首播日期差異，沒有改寫集數或日期。

只有14個候選在本次主來源直接提供同一BG連結；其餘保留的是既有綁定，再以精確原名／版本、條目別名、首播資料及逐筆範圍證據確認，**不宣稱全都來自來源明示連結**。

沿用既有 `summary_scope=full_linked_subject` 精確審查機制，補入57筆簡介範圍核准（其中22筆新增精確身分tuple）。沒有放寬全域名稱正規化或模糊匹配；ID、條目名、日期、卡片或來源原名不同時不能沿用本次核准。已有episode-only對應不自動取得簡介權限；班長／利根川母條目及藥師少女整季／前半仍不允許。
