# 按序實作五項架構改善（2026-10-19）

基準main `d7c7fec0a3603baabde311b19c44c3b93b8445ea`，包含10/19正式資料PR #61。依使用者指定1→5順序，逐項測試、獨立提交，再以同一批PR整合檢查及發布。完整進度見[實作順序](https://github.com/0961282056/anime-static-crawler/blob/ac9875bd20e2e42309f6de093a867e2973926248/docs/%E6%9E%B6%E6%A7%8B%E5%84%AA%E5%8C%96%E5%AF%A6%E4%BD%9C%E9%A0%86%E5%BA%8F-2026-10-19.md)。

## 1. 自動正式站發布驗收

新增唯讀`Verify Production Deployment`：每次main push（含資料PR合併）自動建置相同commit，等待canonical `/release.json`，比對所有季度／資產／搜尋索引與首頁，再用真實Chromium核對卡片原文、來源連結及歷史作品搜尋。Artifacts保留30天，不需要Cloudinary或新增部署密鑰。

結果區分`verified`、`superseded`、`failed`；較新部署必須能證明「目標commit→正式commit→目前main」祖先關係，其他分支／預覽不能當成取代。驗收前後重讀marker，避免切版時混用兩份資料。瀏覽器期間切版也重新確認，不能把瀏覽器失敗直接當成功。逾時留下原因與證據；job失敗可由GitHub通知設定追蹤，未額外發送測試訊息。

實際正式站有Cloudflare自動插入的Pages Analytics。已從基準版本隔離建置並實際比對，確認僅差一段固定格式統計標記。首頁位元組比較只移除**一個固定beacon網址、固定屬性、只有32位hex token設定且無inline程式**的平台插入區塊。其他HTML、額外script或未知屬性仍失敗；其餘公開檔案逐位元組相同才通過。

## 2. 官方來源規則單一化

`services/reviewed_story_sources.json`為唯一人工登錄。建置時從它產生HTML中的前端精確來源對應，移除JS手寫12筆表。拒絕重複卡片、無效ID、非HTTPS及含帳密網址；後端卡片／中日文名／BG／URL／原文綁定不放寬。前端仍驗證對應card、ID、provider、method及URL。

## 3. 圖片、季度與集數工作分離

新流程先收集與解析所有目標季度，再處理封面／完整季度寫入，最後獨立刷新已存在可靠身分的集數。圖片快取命中不建立Cloudinary客戶端；需要新上傳時才建立，每個有上傳的季度仍重新檢查配額。

來源取得／解析／身分契約失敗保留該季原檔。圖片暫時失敗只允許同一精確身分沿用既有合法封面；新卡或不同身分沒有封面時保留整季，不刪卡、不產生假網址。已知外部失敗不阻斷後續獨立集數刷新；磁碟、快取損壞或非預期程式錯誤仍中止。最終持久化沿用所有既有DataRepository防護。

階段結果存`update-stage-report` artifact，包含保留季度、延期封面、metadata失敗及原因。部分工作完成的通知為`PARTIAL`，與完整成功或致命失敗分開。所有故障／quota測試只注入本地fixture；本輪不實際爬取、上傳或刪除Cloudinary資源。

## 4. 資料版本與發布清單

`release.json`記錄commit、程式版本、資料版本、逐季hash，以及所有公開內容檔案的SHA256與大小。發布清單本身不自我雜湊；Cloudflare的`_headers`是平台設定，不列成可下載資產。程式版本涵蓋JS／CSS／模板及生成的官方來源對應，資料版本由季度內容決定。

前端JSON請求依季度hash區分快取；尚未到期但版本不同的cache不能命中，舊版本pending回應不能覆蓋新cache。資料版本切換造成搜尋不一致時，重新載入會讀新清單、清除舊cache再試；程式版本也變更時明確提示重新整理頁面。

## 5. 精簡搜尋索引

建置`search-index.json`，只含精確作品身分、簡介搜尋文字、所屬季度及版本資訊。保留原有名稱／原名／簡介全文搜尋、NFKC及大小寫正規化。搜尋先讀索引，只載入命中作品的最新代表季度（最多4個並行）；同一身分的其他季度保留來源標籤，不為取得標籤重讀整份JSON。

版本範圍仍以完整identity比對，不因名稱相似合併。索引不可缺已收錄季度，重複身分、錯誤季度、版本不符及完整卡片找不到時均不冒充完整結果。零命中不讀其他季度，命中季度失敗會顯示錯誤且可重試，快速取消／切換保持最新請求優先。索引不含封面／集數／完整來源證據，卡片顯示仍讀公開季度原文。

本地37季JSON共3,806,784 bytes，索引1,316,025 bytes（1928個精確身分）；gzip估算由合計993,605降為索引616,740 bytes。特定作品搜尋需索引＋命中季度，已快取季度會重用。**廣泛關鍵字可能命中全部季度，此時會下載索引加全部命中季度，並非每種搜尋都節省傳輸或保證更快。** 詳見[量測與資料不變條件](data-invariants.json)。

## 首次正式驗收的入口修正

PR #62合併為460144e後，正式驗收實際發現Cloudflare會將`/index.html`以HTTP308導向`/`。已調整為直接取得既知同站首頁，繼續拒絕任意重新導向；新增回歸斷言。修正程式已對460144e正式站完成37季2150筆／5資產／首頁／索引共44檔比對。瀏覽器查JSON改用頁面同源fetch，沿用瀏覽器網路與TLS路徑，避免受管環境Node APIRequestContext獨立DNS失敗；沒有改代理、認證或網路規則。初次舊驗收因已知308停止，修正PR合併後以新main自動工作重新驗收，實際結果記於修正PR。
