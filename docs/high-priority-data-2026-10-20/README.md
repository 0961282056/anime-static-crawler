## 修復：來源改名不能撤銷已知的故事範圍限制

《真·中華一番！第二季》anime-712／BG297344先前已有`version_specific_summary_evidence_insufficient`紀錄，保留簡介空白。舊精確別名規則記錄BG標題「真・中華一番！ 続編」；目前API改成「真・中華一番！ 第二期」，正規化後與來源原名一致。

舊`enrich_story()`僅在名稱不同時要求獨立故事範圍核准，因此現在會跳過該保護，直接補入339字的通用旅程介紹。這段描述考試、重返陽泉酒家、得知八種傳說廚具並啟程，先前已判定缺少第二期專屬範圍；第一季條目的中文介紹也敘述相同前提，兩者不是位元組相同的文字，不能宣稱複製比對相等。

[重現與來源證據](story-scope.json)使用基準main的實際函式與真實公開卡片，在隔離記憶體中確認會誤填339字，沒有寫入公開JSON。修復將`summary_scope=requires_review`保存到既有精確身分登錄，以卡片ID、中文名、來源原名及BG ID綁定；在名稱相同的捷徑前檢查，供應者調整標題或空白不會自動撤銷這項決定。取得新且範圍合適的介紹後，必須連同該精確規則重新審查更新。

API與Archive兩種方法、兩種標題空白形式各有回歸，確認保留缺漏且既有可靠介紹不被替換；Archive日期為測試情境，不冒稱本輪下載過歷史dump。集數身分核對仍可用，沒有關閉集數刷新或擴大故事授權。規則只限制明確登錄的卡片，其餘既有可靠資料不變。
