`decision.json`保存實際前後資料、六組編號映射與未確認項目。`businessfish.jp`實測HTTPS 200（119157 bytes），SHA-256在該檔；目前頁面含第三方感想，未驗證營運者身分，不能只因域名／自稱官方就當作一手節目證據。結論以上述配信方的正式目錄為依據。
