### 2. 設定的重查頻率超過請求容量

每輪 Bangumi 上限 **240 次請求**，另有約五分鐘的請求時間預算。由本輪資料計算，24 小時後有 **308 個不同作品身分**到期：77 個連載、230 個狀態未知、1 個未首播。正常 API 至少需要一個作品請求加一個集目請求，因此最低 **616 次**；尚未計入多頁、備援與 1,596 個完結作品的每月重查。

原本固定由最新季度開始，會讓舊作品一直排不到。本輪已改為按最早應重查時間排序，並記錄因額度／時間用盡延後的身分數；未執行的紀錄保留原值與確認時間。這修正長期排不到的問題，**沒有增加吞吐量，也沒有保證連載每天更新**。

[容量模擬](release-audit-2026-10-15/refresh-capacity-simulation.json)固定現有作品狀態、每天成功執行一次、只計完整 API 分頁、不計網路延遲及失敗：原排序跑 90 次後仍有 1,712 個身分未重查，其中六個仍連載；新排序第 45 次才涵蓋全部 1,904 個自動來源身分。這是容量模型，並非正式環境實測或更新時效承諾。

發布前需訂定能達成的更新頻率：優先保障連載與近期作品，降低長期未知／歷史完結的重查頻率或另做分批更新，再用逾期數與確認時間驗證。不能只提高額度而忽略來源限流及時間預算。

## 本輪已修正的正確性問題

- **撤回《1日外出錄班長》的 4／4、已播畢。** 前輪把四個以班長為主線的官方摘要當成完整子作品集目，證據不足。摘要沒有提及班長，不能證明該節目沒有班長短篇。現在總數、完整已播數、完結狀態均為未知；保留官方來源及母條目定位，拒絕套用母作品 24 話。這不代表已證明正確總數一定不是四，而是不能發布四話為確定值。見 [更正依據](release-audit-2026-10-15/hanchou-scope-correction.json)。
- **不再保存早於首播的結束日期。** 即時來源仍把《Classica Loid 第二期》的結束日寫為 2017-03-24（首播 2017-10-07），把《為了在異世界也能撫摸毛茸茸而努力。》寫為 2023-03-24（首播 2024-01-07）。已清空這兩筆不可靠的結束日，保留已核對話數、未知播出狀態與說明，未自行改年份。
- **分頁重複不再冒充完整結果。** 集目 API 或每月作品目錄重複回傳相同 ID，即使列數達到宣告總數，也拒絕採用，交由既有備援／保留機制處理。完整列數不再只靠陣列長度判定。
- **原卡片改名成另一部作品時不沿用舊資料。** 同一卡片 ID 的作品名或已知原名改變時，即使外部 ID 未變或消失，也不帶入舊集數／舊身分，等待重新核對。
- **品質報告補上實際缺口。** 增列未知狀態、未知總數、未知進度、未連結 Bangumi、到期身分及人工快照數，避免只看零 `stale`、零 `conflict` 就判定全部完成。

本輪只修改三筆紀錄的集數中繼資料，其餘 **2,140 筆完全不變**；所有卡片順序、名稱、圖片、星期、時間、簡介與外部 ID 保持原值。人工設定及舊報告已同步標明《班長》的更正，歷史證據檔沒有覆寫。

## 資訊取得方式的檢討

**來源穩定性。** 季度基礎資訊依賴單一 acgsecrets HTML 結構；現有每日 selector canary、有限重試、嚴格解析及原子寫入可防止錯誤頁覆蓋資料，但不能發現所有內容錯誤或歷史漏項。Bangumi API 有限頁數、逾時、請求預算及熔斷，公開頁面可備援；兩者共用 Bangumi 資料庫，不能視為兩個獨立事實來源。404／登入或錯誤頁不當作作品刪除。HTTP 回應大小是在下載後檢查，五分鐘預算也不能視為下載途中可強制中止的硬上限。

**更新時效。** 主分支最近五次正式排程均成功，最近一次爬取與驗證步驟實際執行、沒有資料變更；但使用的是 `d4b9e37`，不包含 PR #38，不能據此宣稱本 PR 的集數流程已在正式環境跑過。排程以台灣 01:00 為目標，這五次建立時間約 04:31～07:33，已有數小時延遲；不能把 GitHub cron 當作準點更新保證。正式排程可見紀錄另存 [production-run-observations.json](release-audit-2026-10-15/production-run-observations.json)。

**官方快照的維護。** 本輪 27 個首要官方網址中九個可即時讀取，其餘 18 個被目前雲端代理的網域限制阻擋；這不是 18 個官方站故障的證據。既有三份證據清單共 34 個檔案的校驗碼全部通過，但校驗碼只能證明證據未被修改，不能代替再次連線查證。《錢天堂》148 話是已核對節目清單，未公告最終總數，不推定完結，也沒有自動 NHK 更新器。未完結人工快照需安排定期人工重查或有完整性檢查的官方來源解析器。

**資訊正確性的邊界。** 通常已播數來自資料庫正篇中首播日期已過的條目；當日、未來、分數編號特別集及日期不完整者不直接計入。這仍不是逐集官方實播或台灣平台上架證明，延期但尚未更正的日期仍可能造成誤差。停播／取消沒有獨立自動偵測依據。原卡片季度可能是預告或續播收錄位置，不能當作作品真正首播季度。建議後續以結構化欄位區分 API、Archive 與官方人工來源及來源版本，並讓逾期狀態能直接反映給讀者。

本輪沒有逐張核對封面圖像內容，也沒有逐作品向電視台核對所有星期與時間。現有欄位與當前聚合來源一致，只能證明來源一致性。瀏覽器測試替換了圖片請求，不能用它證明所有封面網址存活。
