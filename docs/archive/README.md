## 維護方式

新的操作原則更新現行手冊；只有可追查的新證據才新增批次目錄。已結案的待辦由本索引連回 PR 或固定版本，不另複製整份進度。若要刪除證據，先核對 reviewed 規則、測試與清單引用；不可為了減少檔案數破壞可重現性。
