### 來源更新與安全修正

2026 秋原頁明確更新三筆中文譯名：`DARK MACHINE THE ANIMATION`→`闇機 DARK MACHINE`、`Vertex Force`→`至高之力 Vertex Force`、`鐵道行！meet with 鐵道娘`→`鐵旅！meet with 鐵道少女`。《彈珠汽水瓶裏的千歲同學 第二季度》的播出星期由六改二，與既有已審查 2026-10-13 首播日一致；14～24 話、11 集範圍不變。見 [來源候選與原頁雜湊](primary-updates.json)。

重新審查發現：安全的中文譯名更新也會清除原集數快取。因此新增三筆精確譯名審查規則，綁定卡片、原名、兩個外部 ID、舊／新中文名稱及原頁雜湊；只有這些精確變更可保留集數證據，不能用相同 BG ID 加任意中文名繞過版本保護。若改名使人工集數範圍或官方簡介規則失去綁定，阻擋寫入並保留原檔。既有衝突 ID、卡片消失、異版本及惡意改名防護均保留。

38 筆原名僅標點／引號／連字號等書寫不同的身分，逐筆核對來源卡片版本、原名、既有 ID 與首播日期，新增精確條目對應，再重新請求確認。未採名稱搜尋或模糊配對；部分原頁沒有明示 BG 連結，這些保留的是既有綁定，並未聲稱來源明示。只有明確與完整條目同範圍的這 38 筆加上 `summary_scope=full_linked_subject`，允許其原文簡介；原有集數專用別名仍不能搬用母條目介紹。回歸測試包括 plus／base 分界及《1日外出錄班長》不得套用《中間管理錄利根川》簡介。逐筆證據見 [精確別名審查](formatting-alias-review.json)。

依全 1,498 個身分對照首播日期：1,469 相符、23 相差一週內、5 原來源日期不可取得、1 個既有已審查地區日期差異（《一人之下 羅天大醮篇》中國與日本首播）。因此一般資料說明文字改為「依已連結條目的首播日期」，避免把不同地區來源一概稱為日本首播；計算邏輯不變。
